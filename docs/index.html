About the Project

This project documents the integration of AI with RimWorld through the RimMind mod. Initially, I hoped to explore whether an AI could actually play RimWorld — making decisions and controlling the colony autonomously. After setting up RimMind with OpenRouter and Claude, I discovered it functions primarily as an AI chatbot and colony advisor.

The website honestly explains what RimMind does, what it does not do, and outlines the technical work performed to get it running on RimWorld 1.5.4062.

What RimMind Does

RimMind provides an AI interface that can query and understand aspects of the RimWorld colony through various read‑only tools. It does not autonomously control the game.

What It Cannot Currently Do

Be very explicit: the current project does NOT claim to:

  • Automatically play RimWorld
  • Control the mouse or keyboard
  • Independently manage the colony
  • Build structures without human input
  • Independently move colonists
  • Independently fight battles
  • Run an autonomous decision/action loop

These are future research goals, not current capabilities.

Lessons Learned

  • AI integration is not the same as AI control.
  • Giving an AI access to game state does not automatically give it the ability to change the game.
  • Read-only tools and action tools are fundamentally different - observation ≠ intervention.
  • Current RimWorld modding APIs (via HugsLib/Harmony) provide extensive observation capabilities but limited direct action capabilities for complex AI decision loops.
  • Configuration management is crucial - keeping API keys secure while allowing user configuration.
  • Technical compatibility requires attention to API versions and assembly references when working with specific game versions.
